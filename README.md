# 인공지능을 이용한 푸드트럭 앱(기획)
<b>기존 푸드트럭 앱에 트럭의 위치 정보, 결제 서비스, 사용자 데이터를 기반으로 위치 기반 푸드트럭 및 메뉴 추천 기능을 추가할 계획이다. 이를 위해 협업 필터링 알고리즘을 활용하여 많은 사용자로부터 수집된 기호 데이터를 분석하고, 사용자의 관심사를 자동으로 예측하도록 한다. 나아가 하이브리드 추천 시스템을 적용하여, 개별 사용자에게 맞춤형 푸드트럭과 메뉴를 추천함으로써 사용자의 편의성과 만족도를 높이는 것을 목표로 한다.</b>

## 프로젝트 목적과 내용
- 축제 및 박람회 개최 수의 증가에 따라 푸드트럭 운영 수도 증가하고 있다. 그러나 푸드트럭의 이동성으로 인해 소비자가 원하는 트럭을 찾는 데 불편함이 발생하는 문제가 있다. 기존 푸드트럭 앱은 현재 영업 중인 푸드트럭을 확인하고 위치 설정 기능을 통해 근처 트럭을 찾을 수 있으며 사전 결제를 통해 줄을 서지 않고 픽업할 수 있다는 장점이 있다.</br>
- 본 프로젝트에서는 이러한 기존 기능을 확장하여 트럭의 위치 정보, 결제 시스템, 사용자 데이터 및 위치 기반으로 푸드트럭과 메뉴를 추천하는 하이브리드형 인공지능 알고리즘(콘텐츠 기반 필터링 + 협업 필터링)을 탑재함으로써 사용자의 편의성을 한층 강화할 계획이다.</br>

## 문제점 & 수정사항
문제점
1. 처음 기획된 앱은 사업자와 사용자 두 가지로 나누어 사용할 수 있었지만 인공지능을 탑재한 추천 기반 시스템 서비스는 사용자에게 주로 제공되는 서비스로 사업자의 앱 기획이 이 프로젝트와 맞지 않는 것으로 판단.</br>
2. 계절학기 특성상 프로젝트 수행 기간이 짧아 기능 기획만 수행하고 설계는 하지 못함.</br>

수정사항
- 사업자 앱 기획 설계가 프로젝트에 적합하지 않아 제외함.
