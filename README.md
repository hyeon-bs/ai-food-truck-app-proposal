# 🚚 인공지능 기반 맞춤형 푸드트럭 추천 앱 (기획)

## 📝 프로젝트 개요
기존 푸드트럭 플랫폼의 한계를 넘어, **트럭의 실시간 위치 정보, 결제 데이터, 사용자 선호도**를 융합한 AI 기반 맞춤형 푸드트럭 및 메뉴 추천 시스템 기획입니다.</br>
하이브리드 추천 알고리즘(협업 필터링 + 콘텐츠 기반 필터링)을 설계하여 사용자 맞춤형 이벤트를 제공하고 편의성과 서비스 만족도를 극대화하는 것을 목표로 합니다.

## 📅 프로젝트 기간
* 2020.01.02 ~ 2020.01.10 (대학 계절학기 프로젝트)

## 💻 기술 및 기획 스택
* **Design & Prototyping**: Figma
* **AI Algorithm (Conceptual)**: Hybrid Recommendation System (Collaborative Filtering + Content-based Filtering)

## 🎯 프로젝트 목적 및 내용

* **시장 페인 포인트(Pain Point) 해결**
  * 지역 축제 및 박람회 활성화로 푸드트럭 수요는 증가하고 있으나 푸드트럭 특유의 **'이동성'** 때문에 소비자가 원하는 트럭을 실시간으로 찾기 어려운 불편함이 존재합니다.
* **기존 플랫폼 기능 확장**
  * 현재 영업 상태 확인, 실시간 위치 GPS 조회, 사전 결제 및 스마트 픽업 등 기존 앱의 핵심 편의 기능을 그대로 계승합니다.
* **AI 기반 하이브리드 추천 엔진 탑재**
  * 많은 사용자로부터 수집된 기호 데이터를 분석하는 협업 필터링(Collaborative Filtering)과 메뉴/트럭의 특성을 분석하는 콘텐츠 기반 필터링(Content-based Filtering)을 결합하여 개별 사용자 상황(위치, 시간, 선호 음식)에 맞는 최적의 맞춤형 푸드트럭을 자동 예측하여 추천합니다.

## 🔄 프로젝트 한계점 및 수정 사항

### ⚠️ 문제점 및 한계
1. **타겟 아키텍처 불일치**: 초기 기획 시 '사업자 앱'과 '사용자 앱' 두 가지 버전을 동시에 구상했으나 인공지능 추천 서비스의 핵심 가치가 '소비자(사용자) 편의성 극대화'에 집중되어 있어 사업자용 앱 기획은 본 추천 프로젝트의 본질과 맞지 않는 것으로 판단했습니다.
2. **단기 프로젝트의 한계**: 대학 계절학기 특성상 수행 기간(8일)이 매우 짧아 와이어프레임 및 기능 기획 스코프까지만 완료하고 상세 시스템 아키텍처 및 DB 물리 설계 단계까지는 진해하지 못했습니다.

### ✅ 수정 및 보완 사항
* 프로젝트의 핵심 아이덴티티를 명확히 하기 위해 본 추천 시스템 메커니즘과 부합하지 않는 **사업자용 앱 기획 범위를 과감히 제외**하고 사용자 중심의 추천 UI/UX 설계에 집중했습니다.
